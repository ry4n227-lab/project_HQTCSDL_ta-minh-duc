# OctaPoint Developer SDK (TypeScript)

**Phụ trách:** Phạm Hữu Phước  
**Module:** Developer SDK (octapoint-sdk)

## 1. Giới thiệu
Bộ thư viện TypeScript SDK đóng gói sẵn các hàm gọi REST API tới OctaPoint Backend, hỗ trợ xác thực Merchant, quản lý khách hàng, kiểm tra số dư (getBalance) và tra cứu lịch sử giao dịch (getHistory).

## 2. Cách cài đặt & Kiểm thử
Đảm bảo Backend đang chạy tại http://localhost:3000, sau đó mở Terminal tại thư mục octapoint-sdk và chạy:
- Cài đặt thư viện: npm install
- Chạy kịch bản demo: npm run demo
- Đóng gói thư viện: npm run build
